# 地図起点の範囲内比較 + 岡山エリア店舗拡大 設計

## 背景・目的

現状`price-compare-app`は岡山エリア3店舗（マルイ宅配便・イオンネットスーパー・ニシナらくらく便）を対象に、カテゴリ→個別商品のフラットな一覧で価格比較している。今後さらに岡山エリア内の店舗を積極的に増やしていく方針だが、店舗数が増えると「カテゴリ→個別商品」の一覧に無関係に遠い店舗まで混在し、実用性が下がる。そこで、アプリの体験を「地図上で範囲（円）を指定→その範囲内の店舗のみで比較する」という地図起点のフローに転換する。あわせて、岡山エリア内での店舗拡大に着手する。

## スコープ

**対象**:
- 地図起点＋半径内比較機能（フロントエンド全体）
- 岡山エリア内の店舗拡大（候補調査・利用規約確認・スクレイパーアダプタ実装）

**対象外**（今回のスコープではない）:
- 全国規模への拡大（Zの判断により岡山エリア内に限定）
- お気に入り・値下げバッジ・お気に入り機能等の既存機能（変更なし）

## 1. 地図起点＋半径内比較機能

### 全体フロー
1. LocalStorageに保存済みの範囲設定（中心座標・半径）が無い場合、アプリ起動時に地図タブ（`MapView`拡張）を円選択モードで表示する
2. ユーザーは以下のいずれかで中心地点を指定する:
   - 「📍現在地を使う」ボタン（`navigator.geolocation.getCurrentPosition`）
   - 地図上の任意の地点をクリック
3. 右上のフローティングカードで半径（1km〜10kmのスライダー、デフォルト3km）を調整する
4. 「この範囲で決定」ボタンを押すと、中心座標・半径をLocalStorageに保存し、自動的に最安値一覧タブへ遷移する
5. 保存済みの範囲設定がある場合は、起動時に円選択モードをスキップしそのまま最安値一覧タブを表示する（現状の起動フローと同じ）
6. 地図タブにはいつでも「範囲を変更」ボタンを設置し、再度円選択モードに入れるようにする

### データフィルタリング
- 最安値一覧・買い物リスト比較・プリセットのいずれも、LocalStorageに保存された中心座標・半径をもとに、Haversine距離計算で「店舗の緯度経度」と「中心」の距離を算出し、半径以内の店舗のみを対象にする
- 距離計算・フィルタリングは`PriceCompareReal.jsx`のデータ取得後（`products`構築時）に行い、範囲外の店舗しか価格情報が無い商品は一覧から除外する
- 地図タブ自体（円選択モード以外の通常表示）では、範囲内の店舗のピンを強調表示し、範囲外の店舗のピンは薄く表示する（現状の全店舗ピン表示から変更）

### UI
- 円のオーバーレイはLeafletの`L.circle`で描画し、中心・半径の変更にあわせてリアルタイムに再描画する
- 半径スライダーは地図右上の白いフローティングカード内に配置し、「比較範囲: X.Xkm」の数値表示・スライダー・「📍現在地を使う」リンク・「この範囲で決定」ボタンで構成する（クリーン・ミニマルな配色を踏襲）

## 2. 岡山エリア店舗拡大

### 候補
Web検索で以下の候補を確認した:
- **両備まごころネットスーパー**: 楽天の「楽天全国スーパー」プラットフォーム上で運営。既存の2種類のアダプタ（AEON専用の`scraper/lib/aeon.js`、旧ASP共通の`scraper/lib/legacyPlatform.js`）とは異なる新規プラットフォームのため、専用の新規アダプタが必要
- **おかやまコープ**: 会員制の宅配サービス。ゲストで商品一覧・価格を閲覧できるか未確認

### 進め方（自動化できない工程を含む）
店舗ごとの利用規約確認・JANコード取得可否の調査は、過去の3店舗導入時（`.secretary/projects/price-compare-app/project.md`のPhase 0記録参照）と同様、Zとブラウザで一緒に確認しながら進める必要があり完全自動化できない。実装計画には以下の反復可能な調査タスクとして組み込む:
1. 候補サイト（まず両備まごころネットスーパー）のrobots.txt・利用規約を確認し、スクレイピング可否を判断する
2. ゲストモードで商品一覧・価格・JANコード（またはそれに相当する商品識別子）にアクセスできるか、Zと一緒にブラウザで確認する
3. アクセス可能と判断できたら、そのプラットフォーム専用のスクレイパーアダプタ（`scraper/lib/`配下）を実装する
4. 実装後、`stores`テーブルに店舗を追加し、緯度経度をジオコーディングで取得、実データでスクレイピングを実行する

このタスクは1店舗ごとに完結させ、次の店舗候補（おかやまコープ等）は別途同じ手順で追加する。今回の実装計画では、まず地図起点機能を完成させたうえで、両備まごころネットスーパーの調査（Step 1〜2）から着手する。アダプタ実装（Step 3〜4）は調査結果次第で次の実装計画に持ち越す可能性がある。

## テスト・確認方針

- 地図起点機能: ブラウザ実機で以下を確認する
  - 現在地取得・地図クリックでの中心地点変更
  - 半径スライダーの変更が円の見た目に反映されること
  - 「この範囲で決定」→最安値一覧への自動遷移
  - LocalStorage保存後、リロードしても範囲設定が引き継がれ円選択モードがスキップされること
  - 範囲内・範囲外の店舗で一覧の内容が正しく変わること（Haversine距離計算の正しさ）
- 店舗拡大: 新規サイトの調査はZとの対話（ブラウザ確認）が前提のため、実装計画上は「調査タスク」として、Zに確認を仰ぐ設計にする
